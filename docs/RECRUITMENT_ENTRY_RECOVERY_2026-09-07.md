# 招聘入口存储异常与设备恢复

本轮发现并用真实浏览器组件测试复现两项入口缺陷：

1. window.localStorage 属性访问自身抛出 SecurityError 时，异常发生在已有 getItem/setItem 保护外，须知页无法出现。现在先安全获取可选存储，再读取/保存须知开始标记；存储不可用时本页流程仍可继续。
2. 自动连接连续失败三次后，设备恢复不会触发后续连接。保留有限的即时重试，增加 online、focus、devicechange 恢复信号；不新增第二个开始按钮，不定时无限重连，终态场次不启用此恢复。

两个浏览器用例均先失败、修复后通过。全套 test:web 380 项通过；浏览器组件功能测试 18 项通过、3 项仅完整服务模式适用的用例跳过。正式发布构建仍需执行完整 test:functional 和版本一致性验证。

这些是可复现的代码缺陷，不等于已证明某个真实候选人的浏览器发生过同样异常。没有读取该候选人的浏览器存储，也没有代其作答。部署、生产真人全链路、质量复核及并发验收分别记录。

完整服务构建进一步发现外层语言、组织、项目 Provider 同样未保护存储访问，会在面试组件挂载前失败。可选偏好设置现统一通过安全读写辅助函数处理；存储被禁时保留内存状态和正常默认值，不改变登录或权限。完整 Next 服务下的存储拒绝用例已通过，首次失败构建未部署。
