# 招聘出题锚点校验修复记录

2026-09-07，五样本生产验收中一个政府客户岗位样本的四个模型均返回
`question_anchor_invalid`。该批失败并停止扩样，失败任务保持 halted，未自动开启新轮。
旧错误码未区分具体校验分支，因此不能断言四个历史输出都具有相同缺陷。

使用同一已授权测试样本的 HR 只读快照与当前请求构造函数，进行两次限量的离线出题
对照；没有新增投递、面试、候选人消息或重启该 halted 任务。模型正文保留于受保护的
本地验收材料，不复制到仓库或日志。离线模型调用消耗分别为 11,527 和 10,574 token，
这是诊断证据，不是生产面试通过证据。

修复前，数字加分使“3-5年商务/BD经验”在缺少维度关键词时压过具体工作职责。
三道题未通过岗位锚点校验：既有改写造成的字面匹配问题，也有省略年限的情况。
不能将所有拒绝直接放行。

修复后，岗位锚点选择不再因包含数字而获得额外分数；简历量化成果仍保留原有排序。
出题指令要求先引用原文并保留数字、年限、单位和术语，再提出与两项事实相连的问题。
缺少来源、缺少简历锚点、缺少岗位锚点和岗位类型不符分别产生固定的安全错误码，
附带固定维度名称；不记录简历、联系方式或模型正文。双锚定校验保持启用。

修复后的离线输出六道题均通过原有匹配检查，六个岗位引文均完整保留。
行为测试覆盖岗位职责与通用数字要求的排序、实际提示词构造及实际 provider 校验回调，
并验证缺失锚点与错误岗位题型仍被拒绝。正式构建和部署后须重新执行受影响的
单样本、多样本及并发验收；此记录不能代替这些证据。
